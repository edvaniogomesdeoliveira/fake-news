Documentação do Projeto: Fake News e Desinformação

Guia completo de funcionamento do arquivo index.html

1. Descrição Geral

O arquivo index.html é a página principal do projeto "Fake News e Desinformação". Ele contém um cabeçalho com imagem, seções informativas sobre fake news, um vídeo explicativo, uma lista de subtemas importantes, um gráfico e uma ferramenta de verificação de notícias.

2. Estrutura do Arquivo

2.1 Cabeçalho

Exibe uma imagem e o título principal do site.

<header>
  <div class="container-imagem">
    <img src="fakenews.jpg" alt="fake news">
  </div>
  <h3>Fake News e Desinformação</h3>
  <p class="subnav">Entenda o impacto...</p>
</header>

2.2 Seção "O que são Fake News?"

Explica o conceito de fake news e inclui um vídeo incorporado do YouTube.

2.3 Subtemas Importantes

Lista com links externos de artigos relevantes.

2.4 Gráfico

Exibe uma imagem contendo estatísticas sobre fake news no Brasil.

2.5 Verificador de Notícias

Esta seção permite que o usuário insira uma URL ou texto para verificar a veracidade. Utiliza a API do Google Fact Check Tools.

3. Formulário de Mensagem (EmailJS)

Permite que o usuário envie mensagens diretamente para o seu e-mail. É usado o serviço EmailJS. 

emailjs.send("SEU_SERVICE_ID", "SEU_TEMPLATE_ID", { mensagem: message })

4. Dependências Externas

  • Google Fact Check Tools API
  • EmailJS
  • YouTube Embed

5. Imagens Utilizadas

  • fakenews.jpg – imagem do topo
  • news.png – ícone do site

6. Arquivo CSS Externo

O arquivo principal importa o estilo através de:

<link rel="stylesheet" href="style.css">

A formatação visual geral do site, incluindo cores, espaçamentos e responsividade, está definida no arquivo style.css.
